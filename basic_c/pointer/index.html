    Pointer란?

    메모리 주소를 저장하는 변수.

    &와 *의 차이는 아래와 같음

    1. & (주소 연산자, address-of) 변수 앞에 붙여서, 그 변수의 메모리 주소를 구함. (타입 뒤에 붙는 & 는 참조자 (reference) 선언)

      • (간접 참조 연산자, dereference) 포인터 변수 앞에 붙여서, 그 포인터가 가리키는 주소의 값을 가져옴. 즉, 주소를 “열어서 안에 있는 값”을 꺼내는 것.
    int a = 10;
int *p = &a;       // p에 a의 주소 저장
printf("%d\n", *p); // p가 가리키는 곳(a)의 값(10) 출력
*p = 20;            // p가 가리키는 곳(a)의 값을 20으로 변경

    초기화 해주지 않은 포인터의 예

    #include <iostream>
int main() {
    int* p;  // 초기화 안됨
    std::cout << p << "\n";  // p에 들어있는 임의의 메모리 주소 출력
}

    여러 번 실행해보면 쓰레기 값이 계속해서 바뀌면서 출력이됨.

    이는 위험한 상황을 초래할 수도 있기 때문에, 웬만하면 int * p = nullptr; 로 초기화해주는 습관 필요.

    잘 되는 예 vs (일부러) 터지는 예

    ✅ 정상 예

    #include <iostream>
int main() {
    int a = 10;
    int* p = &a;   // 주소 저장
    *p = 42;       // 역참조로 실제 메모리의 값을 수정
    std::cout << a << "\n";   // 42
}

    ❌ 1) 초기화 안 된 포인터 역참조 (거의 100% 터짐)

    int main() {
    int* p;   // 쓰레기 주소
    *p = 7;   // 정의되지 않은 동작(UB): 보통 즉시 크래시(세그폴트)
}

    ❌ 2) 널 포인터 역참조

    int main() {
    int* p = nullptr;
    *p = 7;   // UB: 보통 크래시
}

    ❌ 3) 댕글링 포인터(스코프 끝난 뒤의 주소 사용)

    int* leak() {
    int x = 123;
    return &x;  // 지역 변수 주소를 리턴 → 이미 무효가 될 주소
}
int main() {
    int* p = leak();
    *p = 5;     // UB: 운 좋으면 크래시, 운 나쁘면 조용히 데이터 깨짐
}

    ❌ 4) 해제 후 사용(use-after-free)

    int main() {
    int* p = new int(10);
    delete p;
    *p = 3;     // UB: 해제된 메모리 접근 → 크래시/데이터 훼손
}

    포인터 오류 3종(Dangling/NULL/Wild)의 비교는 Error_Pointer 참고.

    함수 포인터 (Function Pointer)

    포인터는 변수의 주소뿐 아니라 함수의 주소도 담을 수 있음. 코드(.text 영역 )도 메모리에 있으므로 주소가 있기 때문.

    #include <iostream>
using namespace std;

// 함수 정의
int sayHello() {
    cout << "Hello!" << endl;
    return 0;
}

// 함수 포인터 타입 정의
typedef int (*FuncType)();

int main() {
    // 함수 포인터 변수 선언 (함수 이름 = 함수의 주소)
    FuncType funcPtr = sayHello;

    // 함수 포인터로 함수 호출
    funcPtr();

    return 0;
}
    • 선언 문법: 반환타입 (*이름)(인자타입들) — 예: int (*fp)(int, int). 괄호가 없으면(int *fp(int)) “포인터를 반환하는 함수” 선언이 되므로 주의
    • 용도: 콜백 등록(qsort의 비교 함수), 테이블 기반 분기, 플러그인 구조 등 — 상세와 활용 패턴은 Function_Pointer , Callback_function 참고
