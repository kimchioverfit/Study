    01 Basic Commands

    Git 기본 명령어 — 생성 / 기록 / 확인

    전체 공간 개념은 00. 개요 참고.

    1. 저장소 생성 & 설정

    명령어설명
    git init현재 폴더를 Git 저장소로 초기화 (.git 생성)
    git clone <url>원격 저장소를 로컬로 복제
    git config --global user.name "이름"커밋에 기록될 이름 설정
    git config --global user.email "메일"커밋에 기록될 이메일 설정
    git config --list현재 설정 전체 확인

    2. 변경 기록 (add / commit)

    명령어설명
    git status변경/스테이징 상태 확인
    git add <file>특정 파일을 스테이징
    git add .변경된 모든 파일을 스테이징
    git restore --staged <file>스테이징 취소 (working directory는 유지)
    git commit -m "메시지"스테이징된 변경을 커밋
    git commit -am "메시지"추적 중인 파일을 add + commit 한 번에 (신규 파일 제외)
    git commit --amend직전 커밋 수정 (메시지/내용 고쳐 덮어쓰기)

    ⚠️ --amend는 커밋 해시를 새로 만듦. 이미 push한 커밋에는 쓰지 말 것 (히스토리 재작성 → 협업자와 충돌). 자세한 이유는 04. Rebase 황금률 참고.

    3. 히스토리 확인

    명령어설명
    git log커밋 히스토리
    git log --oneline --graph --all그래프 형태로 한 줄씩 (브랜치 흐름 보기 최적)
    git show <commit>특정 커밋의 상세 변경 내용
    git diffworking directory vs 스테이징 차이
    git diff --staged스테이징 vs 마지막 커밋 차이
    git blame <file>각 줄을 누가/언제 바꿨는지
