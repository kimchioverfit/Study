# 1. Post-Training Quantization (PTQ)

| 특징    | 설명                             |
| ----- | ------------------------------ |
| 적용 시점 | 학습 이후                          |
| 대상    | weight만 또는 weight + activation |
| 정밀도   | FP32 → INT8 or FP16            |
| 장점    | 간단, 빠름, 학습 필요 없음               |
| 단점    | 정확도 손실 가능성                     |

하위 유형:

`Dynamic Quantization`

weight만 INT8로 변환하고, activation은 FP32로 유지 

(runtime에 quantization) 주로 RNN, Transformer 계열에서 많이 사용

`Static Quantization`

weight + activation 모두 양자화

calibration data로 범위(min/max) 측정 필요

`Weight-only Quantization`

weight만 quantize (activation은 그대로)


### sample
```python
# Post Training Static Quantization (PyTorch)
import torch.quantization

model_fp32 = YourModel()
model_fp32.eval()
model_fp32.qconfig = torch.quantization.get_default_qconfig('fbgemm')
torch.quantization.prepare(model_fp32, inplace=True)
torch.quantization.convert(model_fp32, inplace=True)
```
