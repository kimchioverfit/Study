Knowledge Distillation(지식 증류)은 **큰 모델(Teacher)** 이 가진 지식을 **작은 모델(Student)** 에게 전달하여,
 작은 모델이 높은 성능을 내도록 학습시키는 모델 압축 기법입니다. 특히 리소스가 제한된 환경(모바일, IoT, 임베디드 등)에서 자주 사용됩니다.


 ### 🔍 핵심 개념 요약

 | 구분       | 설명                                        |
| -------- | ----------------------------------------- |
| 목적       | 큰 모델의 성능을 유지하면서 작은 모델로 경량화                |
| 주요 구성 요소 | Teacher 모델, Student 모델, Distillation Loss |
| 장점       | 모델 경량화, 추론 속도 향상, 적은 연산자원 사용              |


---

### 📘 기본 아이디어

일반적으로 딥러닝 모델은 **ground truth (정답 레이블)** 에 대해 학습. 

하지만 지식 증류는 아래처럼 **Teacher 모델의 예측값(logit, soft target)** 까지 학습에 활용
```
Teacher(x) → soft target (ex: [0.2, 0.7, 0.1])
Student(x) → soft target' ≈ soft target

정답: y = [0, 1, 0]
```
즉, Student는 단순히 정답(y)만 모방하는 게 아니라, Teacher의 예측 분포까지 모방하며 "더 똑똑하게" 학습

---

### sample
```python
import torch.nn.functional as F

def distillation_loss(student_logits, teacher_logits, labels, T=2.0, alpha=0.7):
    # student - ground truth loss
    ce_loss = F.cross_entropy(student_logits, labels)
    
    # student - teacher loss (soft targets)
    soft_student = F.log_softmax(student_logits / T, dim=1)
    soft_teacher = F.softmax(teacher_logits / T, dim=1)
    kd_loss = F.kl_div(soft_student, soft_teacher, reduction='batchmean') * (T ** 2)
    
    return alpha * ce_loss + (1 - alpha) * kd_loss
```
