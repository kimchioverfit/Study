# Type size

| 타입            | 크기 (바이트)               | 비고                   |
| ------------- | ---------------------- | -------------------- |
| `bool`        | 1                      | 논리값 (`true`/`false`) |
| `char`        | 1                      | 문자 1글자 (ASCII 등)     |
| `short`       | 2                      | 16비트 정수              |
| `int`         | 4                      | 32비트 정수              |
| `long`        | 4 (Windows), 8 (Linux) | 플랫폼 차이 있음            |
| `long long`   | 8                      | 64비트 정수              |
| `float`       | 4                      | 32비트 부동소수점           |
| `double`      | 8                      | 64비트 부동소수점           |
| `long double` | 8\~16                  | 컴파일러에 따라 다름          |
| `void*` (포인터) | 8                      | 64비트 주소값             |
