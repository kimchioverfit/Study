New malloc

new 와 malloc 비교

C++의 new/delete와 C의 malloc/free는 둘 다 heap에서 동적 할당을 하지만 객체냐 순수 메모리 블록이냐라는 근본적인 차이가 있다.

malloc/calloc/realloc 자체의 사용법과 버그(누수, double free, dangling pointer)는 malloc 문서 참고. 여기서는 new와의 차이만 다룬다.

구분new (C++)malloc (C)
반환 타입요청한 타입의 포인터 → 형변환 불필요void* → C++에선 형변환 필요
생성자 호출호출함 (객체 초기화)호출하지 않음
소멸자 호출delete 시 호출됨free 시 호출 안 됨
크기 지정타입 크기 자동 계산직접 sizeof로 지정
실패 시std::bad_alloc 예외 (기본)NULL 반환
연관 함수delete, delete[]free
오버로딩가능 (operator new 재정의)불가능
초기화new int(5)처럼 할당+초기화 동시 가능없음 (직접 memset 등)

핵심 차이 — 생성자/소멸자 호출 여부

new와 malloc의 차이는 결국 이 한 줄로 요약된다: malloc은 메모리만 빌려주고, new는 그 메모리 위에 객체를 생성한다.

struct Widget {
    Widget() { /* 초기화 로직 */ }
    ~Widget() { /* 정리 로직 */ }
};

Widget *a = new Widget();      // 메모리 할당 + 생성자 호출
Widget *b = (Widget *)malloc(sizeof(Widget));  // 메모리만 확보 — 생성자 호출 안 됨, 멤버가 쓰레기 상태

delete a;    // 소멸자 호출 + 메모리 해제
free(b);     // 메모리만 해제 — 소멸자 호출 안 됨, 멤버가 들고 있던 자원(포인터 등) 누수

b처럼 malloc으로 만든 객체는 생성자가 안 돌아서 멤버가 초기화되지 않고, free로 지울 때도 소멸자가 안 돌아 그 객체가 소유하던 자원(내부 포인터, 락 등)이 그대로 새 버린다. C++ 객체를 다룰 땐 malloc/free를 쓰면 안 되는 이유가 이것.

결론

  • C++ 객체 생성 → new/delete (생성자·소멸자 자동 처리)
  • C 스타일 순수 메모리 블록 → malloc/free (초기화·정리는 직접)
  • 섞어서 쓰면 안 됨 — new로 만든 걸 free, malloc으로 만든 걸 delete 하는 것 둘 다 undefined behavior (생성자/소멸자 호출 여부가 서로 다르기 때문)
  • 실전 C++ 코드에서는 new/delete조차 직접 쓰지 않고 Smart Pointer (unique_ptr/make_unique 등)로 감싸는 것이 표준이다 — 해제를 잊거나 예외 중 누수되는 경로 자체를 없애기 위함
