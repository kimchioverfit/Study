Static

static은 어디에 존재하느냐에 따라 다양한 의미를 가진다.

  1. 함수/블록 내부에서 static (지역 정적 변수)

수명: 함수가 끝나도 파괴되지 않고, 프로그램이 종료될 때까지 유지됨.

초기화: 처음 그 줄이 실행될 때 딱 한 번만 초기화됨. (C++11부터 스레드 안전 보장)

void foo() {
    static int x = 100; // 한 번만 초기화
    x++;
    std::cout << x << "\n";
}

foo();
foo();
foo();

위와 같이 호출 시 출력은 101, 102, 103임.

이렇게 동작하는 이유는 , static 선언 시 다른 변수들처럼 stack 영역에 저장되는 것이 아니라,

data 영역에 저장되기 때문. (“data 영역” = 프로그램 실행 시 OS가 프로세스 주소 공간 안에 만들어 주는 전역/정적 변수 전용 메모리 공간)

┌───────────────┐ 높은 주소 │ Stack │ (지역 변수, 매개변수) │ ↓ │ ├───────────────┤ │ Heap │ (new/malloc 동적 할당) ├───────────────┤ │ BSS segment │ (초기값 없는 전역/정적 변수 → 0으로 채움) │ Data segment │ (초기값 있는 전역/정적 변수) ├───────────────┤ │ Text segment │ (실행 코드, 리터럴 상수) └───────────────┘ 낮은 주소

참조 프로세스

  1. 전역/네임스페이스 스코프에서 static

의미: 내부 연결(internal linkage). → 해당 변수나 함수는 정의된 번역 단위(.cpp) 안에서만 사용 가능.

다른 소스파일에서 접근 불가.

  1. 클래스 안에서 static 데이터 멤버

특징: 모든 객체가 공유하는 “클래스 소속” 변수.

정의: C++17 전에는 클래스 밖에서 따로 정의 필요, C++17 이상은 inline static 가능.

  1. 클래스 안에서 static 멤버 함수

특징: this 포인터가 없고, 객체 없이도 호출 가능.

제한: 인스턴스 멤버에는 접근 불가. 오직 정적 멤버나 인자로 넘긴 객체만 사용 가능.
