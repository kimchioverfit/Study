# 2.Structured Pruning

채널, 필터, 노드 단위로 통째로 제거하는 pruning 기법

예: Conv 레이어의 output 채널 전체 삭제, FC 레이어의 뉴런 단위 제거

---

### 🔍 2. 비구조화와 비교

| 항목       | Unstructured    | **Structured**        |
| -------- | --------------- | --------------------- |
| 제거 단위    | 개별 weight (스칼라) | **채널, 필터, 노드** 등 큰 단위 |
| 모델 구조 변화 | 없음 (희소화)        | **구조 자체가 작아짐**        |
| 추론 속도    | 느림 (별도 최적화 필요)  | **실제로 빨라짐**           |
| 하드웨어 최적화 | 어려움             | **GPU/CPU 친화적**       |
| 구현 난이도   | 쉬움              | 비교적 어려움               |

---

### 🎯 3. Pruning 대상
| 레이어         | 대상                                   |
| ----------- | ------------------------------------ |
| Conv2D      | **Output 채널(channel)**, 커널 필터        |
| Linear (FC) | 노드 (행/열 단위)                          |
| BatchNorm   | 채널 단위                                |
| Transformer | Attention Head, FeedForward Layer 차원 |


---

### sample
```python
import torch
import torch.nn.utils.prune as prune
import torch.nn as nn

model = nn.Sequential(
    nn.Conv2d(3, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(64, 128, kernel_size=3, padding=1)
)

# 첫 Conv 레이어의 output 채널 중 30% 제거 (L2 norm 기준)
prune.ln_structured(model[0], name="weight", amount=0.3, n=2, dim=0)

# 마스크 확인
print(model[0].weight_mask.shape)

# pruning 적용 후 mask 제거 → 실제 weight 저장
prune.remove(model[0], "weight")

```
