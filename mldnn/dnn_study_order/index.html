    0단계 · 기초 개념

    신경망이 무엇을 계산하고 어떻게 학습하는지. 여기가 비면 뒤가 전부 흔들림.

    순서문서상태
    1ML & DL — 머신러닝과 딥러닝의 관계✅
    2Feature — “특징"이 무슨 뜻인지✅
    3딥러닝이 푸는 문제들✅

    문제 유형은 필요할 때 찾아봐도 됨 — Classification · Regression · Clustering · Dimensionality Reduction · 특수 목적

    순서문서상태
    4Hidden layer → 예제✅
    5Neural Network 예제✅

    7nn Function✅

    0.3 모델을 구역으로 나눠 보기

    논문을 읽을 때 “이 부분이 어디에 해당하나"를 잡아주는 어휘임. 2단계 이후 계속 나옴.

    순서문서상태
    8Backbone — 특징 추출기✅
    9Neck — 특징을 섞는 중간 단계✅
    10Head — 최종 예측을 내는 부분✅
    11Encoder / Decoder✅

    Decoder 문서의 “세 가지 디코더"는 꼭 보고 갈 것. NLP 디코더 · DETR 디코더 · U-Net 디코더가 전부 다른 뜻이라 나중에 반드시 헷갈림.

    0.4 학습이 돌아가는 원리

    순서문서상태
    12학습 파이프라인✅
    13Activation Function✅
    14Loss function✅
    15Autograd — 자동 미분✅

    활성함수 개별 문서는 필요할 때 참고 — Sigmoid · Softmax · ReLU · Tanh

    손실함수도 마찬가지 — BCE · CCE · SCCE · MSE · MAE · Huber

    분류면 Cross Entropy, 회귀면 MSE/MAE 정도만 먼저 잡고 넘어가도 됨.

    0.5 실습 환경

    순서문서상태
    16PyTorch✅

    이후 단계의 코드 블록을 직접 돌려보려면 여기가 필요함.

    1단계 · CNN과 Backbone

    이미지를 다루는 기본기. 여기부터 Vision 역사 문서 와 흐름이 겹침.

    순서문서왜 읽나상태
    17CNNconvolution이 뭘 하는지✅
    18AlexNet (2012)딥러닝이 실제로 이긴 첫 사례✅
    19VGG (2014)3×3을 깊게 쌓는 설계⬜ 링크만
    20ResNet (2015)residual — 이후 모든 모델이 씀⬜ 링크만
    21EfficientNet깊이/너비/해상도 스케일링⬜

    ResNet의 residual connection은 Transformer에도 그대로 들어감. 3단계 전에 개념만은 잡아둘 것.

    2단계 · 고전 Object Detection

    “물체가 어디 있는지"를 푸는 방법이 어떻게 발전했는지. 문제 정의 → 느린 해법 → 빨라지는 과정의 교과서적 사례임.

    순서문서핵심상태
    22Efficient Graph-Based Segmentation딥러닝 이전의 영역 분할✅
    23Selective Search후보 영역 제안✅
    24OverFeat (2013)sliding window + CNN✅
    25R-CNN (2014)후보 영역마다 CNN — 느림✅
    26Fast R-CNNfeature map을 한 번만 계산✅
    27Faster R-CNN (2015)후보 영역 제안까지 신경망으로✅
    28FPN다중 스케일 특징⬜
    29Mask R-CNN검출 + 분할🟡
    30SSD / YOLOone-stage — 속도 우선⬜
    31RetinaNetFocal Loss, 클래스 불균형⬜
    32FCOSanchor-free⬜

    실습으로 Mask R-CNN 학습 코드 구조 를 같이 보면 좋음.

    읽고 나서 회고 — Mask R-CNN 오용 을 볼 것. 문제에 안 맞는 모델을 계속 쓰면 어떻게 되는지에 대한 기록이라, 논문만 읽을 때는 안 보이는 부분임.

    3단계 · Transformer

    2단계와 독립적으로 읽어도 됨. 4단계의 전제라서 여기를 대충 넘기면 ViT·DETR에서 반드시 막힘.

    순서문서핵심상태
    33Token문장 → 토큰 → ID. tokenizer가 하는 일✅
    34Embedding Layer토큰 → 벡터✅
    35Dimension$d$ 는 설계자가 정함. 키울 때의 대가✅
    36Self-Attention여기가 핵심. 직관 → Q/K/V → 숫자 예제✅
    37Positional Encodingattention이 순서를 모르는 문제✅
    38FFN토큰별 가공✅
    39Cross-Attention한 시퀀스가 다른 시퀀스를 참조✅
    40Attention Is All You Need위를 합친 전체 구조✅

    순서를 눈여겨볼 것 — 논문 정리를 마지막에 둠. 원 논문은 $Q/K/V$ 수식부터 시작해서 처음 보면 난도가 급격히 올라감. 부품을 먼저 익히고 조립하는 쪽이 훨씬 수월함. 이미 한 번 본 적 있으면 38번부터 읽고 막히는 곳만 되짚어도 됨.

    4단계 · Vision Transformer

    Transformer를 이미지에 적용하면서 vision이 다시 한 번 바뀐 구간임.

    순서문서핵심상태
    41ViT (2020)이미지를 패치로 잘라 토큰 취급✅
    42DETR (2020)object query + 헝가리안 매칭, NMS 제거✅
    43U-Net / DeepLab분할 쪽 고전 — 필요할 때⬜
    44Swin Transformer계층적 ViT, 윈도우 attention⬜
    45EfficientFormer모바일 지연시간 관점 최적화✅
    46EoMT (2026)plain ViT만으로 segmentation✅
    47SAM파운데이션 모델 (optional)⬜

    DETR 을 EoMT 보다 먼저 볼 것. “쿼리가 이미지를 보고 물체를 집어 온다"는 개념이 DETR에서 나오고, EoMT는 그 구조를 덜어내는 이야기라 순서가 뒤집히면 이해가 안 됨.

    5단계 · 곁가지

    본류를 마친 뒤 관심사에 따라 고르면 됨.

    Amodal Segmentation

    가려진 부분까지 예측하는 갈래. 2단계(Mask R-CNN)가 전제임. 자체 순서가 개요 문서 에 정리돼 있음 — 논문 7개를 연대순으로 따라감.

    문제 정의 → 데이터셋 → ORCNN → KINS → De-Occlusion → BCNet → Amodal SAM

    Generative Model

    문서상태
    Auto-Encoding Variational Bayes (VAE)✅

    Encoder / Decoder 개념이 먼저임. VAE의 디코더는 또 다른 뜻으로 쓰임.

    6단계 · 모델 최적화

    모델을 실제로 쓰는 단계에서 필요함. 4단계까지 끝낸 뒤 봐도 늦지 않음.

    순서문서상태
    48Optimization 개요✅
    49Pruning 개요 → Unstructured → Structured✅
    50Quantization 개요 → PTQ → QAT✅
    51Integer-only · FP16/BF16✅
    52Knowledge Distillation✅

    FFN 문서의 “파라미터의 2/3가 FFN에 있음"이 여기서 의미를 가짐 — 프루닝·양자화의 주요 타깃이 되는 이유임.

    최소 경로

    시간이 없으면 이것만이라도.

    진행 체크리스트

    • 0단계 — Backbone/Neck/Head를 보고 모델 그림을 구역으로 나눠 말할 수 있음
    • 0단계 — 분류에 Cross Entropy를 쓰는 이유를 설명할 수 있음
    • 1단계 — residual connection이 왜 필요한지 설명할 수 있음
    • 2단계 — R-CNN → Fast → Faster에서 무엇이 빨라졌는지 각각 말할 수 있음
    • 3단계 — $QK^\top$ 이 왜 토큰 관계를 나타내는지 설명할 수 있음
    • 3단계 — $\sqrt{d_k}$ 로 나누는 이유를 설명할 수 있음
    • 3단계 — Self-Attention과 Cross-Attention의 차이를 Q/K/V 출처로 설명할 수 있음
    • 4단계 — ViT가 이미지를 어떻게 토큰으로 바꾸는지 설명할 수 있음
    • 4단계 — DETR이 NMS를 없앨 수 있는 이유를 설명할 수 있음
