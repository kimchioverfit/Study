1.Unstructured Pruning

딥러닝 모델의 weight(가중치) 중

값이 작거나 중요도가 낮은 개별 요소들을 제거하여

희소(sparse) 구조를 만드는 경량화 기법

모델 저장 & 추론

weight가 0인 값이 많은 sparse tensor 형태이므로, 저장 용량은 작아짐

⚠️ 하지만 PyTorch, TensorFlow 등에서는 기본적으로 sparse 연산을 최적화하지 않음

→ 추론 속도는 그대로, 모델 크기만 감소

따라서 ONNX + TensorRT, AMPERE GPU, custom inference engine 등에서 진짜 속도 향상을 체감 가능

Sample

import torch.nn.utils.prune as prune
import torch.nn as nn

# 간단한 모델
model = nn.Sequential(
    nn.Linear(512, 256),
    nn.ReLU(),
    nn.Linear(256, 10)
)

# 첫 번째 Linear 레이어에 대해 30% 비구조화 pruning 적용
prune.l1_unstructured(model[0], name="weight", amount=0.3)

# 마스크 확인 (1: 유지, 0: 제거)
print(model[0].weight_mask)

# 영구적으로 weight만 남기고 pruning mask 제거
prune.remove(model[0], 'weight')
