1.Feature

Feature (특징)

Feature(특징) — 데이터를 구분하고 판단하는 데 쓰이는 의미 있는 정보 한 조각. 모델은 raw 데이터 자체가 아니라, 거기서 뽑아낸 feature를 보고 결정을 내린다.

🔷 1. 정의

머신러닝/딥러닝 모델의 입력이 되는 속성(attribute)·패턴을 feature라고 한다.

  • “모델이 보는 단서"라고 생각하면 된다.
  • 좋은 feature를 쓰면 → 모델이 패턴을 쉽게 학습.
  • 나쁘거나 부족한 feature → 아무리 좋은 모델도 예측 불가.

핵심: “무엇을 보고 판단할 것인가” 를 정하는 것이 feature다.

🔷 2. 두 가지 맥락 (정형 데이터 vs 이미지)

같은 “feature"라는 단어가 데이터 종류에 따라 조금 다르게 쓰인다.

맥락feature의 의미예시
정형 데이터 (Tabular / 전통 ML)표의 열(column) = 변수/속성집값 예측: 평수, 방 개수, 지하철까지 거리 각각이 feature
이미지 / CNN이미지에서 뽑아낸 시각적 패턴엣지, 질감(texture), 코너, 눈·바퀴 같은 물체 부위

정형 데이터에서 feature는 사람이 정해 둔 변수이고, 이미지에서 feature는 모델이 픽셀에서 찾아내는 패턴이다. (→ §5)

🔷 3. Feature의 계층 (Low-level → High-level)

특히 CNN 같은 딥러닝 모델은 feature를 층층이 쌓아 점점 추상적인 것으로 발전시킨다.

수준feature 예시추출 위치
저수준 (low-level)엣지, 색, 밝기 변화, 코너앞쪽 층
중간 수준 (mid-level)질감, 곡선, 단순 도형중간 층
고수준 (high-level)눈, 바퀴, 얼굴, 물체 전체뒤쪽 층
flowchart LR
    P["픽셀"] --> A["엣지 · 색<br/>저수준"] --> B["질감 · 도형<br/>중간"] --> C["물체 부위<br/>고수준"] --> D["물체 전체"] --> E["판단"]

앞쪽 층의 단순한 feature들이 조합되어 뒤쪽 층의 복잡한 feature가 만들어진다.

⭐ 4. Feature vs Filter vs Feature map (꼭 구분)

CNN 문맥에서 가장 헷갈리는 세 단어. 정확히 구분하자.

용어정의비유
Filter (필터/커널)“이런 패턴을 찾아라"라는 탐지기 (학습되는 가중치)도장(stamp)
Feature (특징)그 필터가 반응하는 패턴 그 자체도장이 찍는 모양
Feature map (특징 맵)필터를 이미지 전체에 적용해 얻은 결과 = “그 feature가 어디에, 얼마나 강하게 있는지"의 2D 지도도장을 곳곳에 찍어본 결과지
flowchart LR
    F["filter 탐지기<br/>예: 세로 엣지 찾기"] -->|"슬라이딩 · 합성곱"| M["feature map<br/>값이 클수록 그 위치에<br/>세로 엣지가 강하게 존재"]
  • 즉 filter는 도구, feature는 찾는 대상, feature map은 그 결과 분포도.
  • 자세한 계산 과정(합성곱 → feature map)은 → CNN.md §3 참고.

🔷 5. Feature Engineering vs Feature Learning

feature를 누가 만드는가가 전통 ML과 딥러닝의 결정적 차이다.

구분누가 feature를 만드나방법
Feature Engineering (전통 ML)사람이 수작업 설계HOG, SIFT, 색 히스토그램, 도메인 지식 기반 변수 생성
Feature Learning (딥러닝)모델이 자동 학습필터 가중치를 학습 하며 유용한 feature를 스스로 발견

0.Basic.md 에서 “머신러닝은 인간이 Feature 가중치를 설정해야 하지만, 딥러닝은 자기가 찾아서 함“이라고 한 것이 바로 이 차이다. 그래서 CNN을 feature extractor(Backbone )라고 부른다 — 핵심 역할이 feature를 자동으로 뽑아내는 것이기 때문.

🔷 6. 우리 저장소에서 feature가 등장하는 곳

표현의미문서
feature extractorfeature를 뽑아내는 부분(주로 CNN)Backbone
특징 추출 (feature extraction)입력을 의미 있는 표현으로 변환Encoder , Hidden layer
feature map / feature vector추출된 feature의 2D 지도 / 1D 벡터CNN , R-CNN
feature 수 ↕ (과적합/과소적합)feature가 너무 많으면 과적합, 적으면 과소적합Terms
차원 축소 = feature 수 줄이기고차원 데이터를 적은 feature로 압축Dimensionality Reduction

🔷 7. 좋은 feature의 조건

조건설명
변별력 (Discriminative)클래스/값을 잘 구분해 줄 수 있어야 함
불변성 (Invariance)위치·크기·밝기가 조금 변해도 같은 feature로 인식 (CNN의 이동 불변성 )
간결성 (Compactness)중복·노이즈 없이 핵심 정보만 담아야 학습 효율↑

📌 요약

  • Feature = 데이터에서 뽑아낸, 판단에 쓰는 의미 있는 패턴/속성.
  • 정형 데이터에선 변수(열), 이미지에선 시각적 패턴(엣지·물체 부위).
  • CNN은 feature를 저수준 → 고수준으로 층층이 학습한다.
  • filter(탐지기) → feature(패턴) → feature map(분포 지도) 순서로 이해.
  • 전통 ML은 사람이 feature를 설계(engineering), 딥러닝은 모델이 자동 학습(learning).
