Vision Overview

Vision 역사 한눈에 보기 (Computer Vision Overview)

Region Proposal(저수준 분할) → Backbone(특징 추출) → Object Detection/Segmentation → Transformer 기반 최신 Vision 모델로 이어지는 컴퓨터 비전 발전사를 한눈에 정리한 문서. 각 항목은 실제 정리 문서로 연결되며, 아직 문서가 없는 항목은 링크 없이 이름만 표기했다. (전체 작성 현황은 §7 참고)

🔷 1. 전체 흐름 한눈에 보기

flowchart TD
    A[Low-level segmentation / region proposal] --> A1[Efficient Graph-Based Segmentation]
    A --> A2[Selective Search]

    A2 --> Z[CNN 기본 개념]
    Z --> B[Backbone CNN evolution]
    B --> B1[AlexNet]
    B1 --> B2[VGG]
    B2 --> B2b["GoogLeNet / Inception"]
    B2b --> B3[ResNet]
    B3 --> B4[EfficientNet]

    B4 --> C[Object Detection]

    C --> C1["OverFeat\nsliding window"]
    C --> C2[R-CNN family]
    C2 --> D1[R-CNN]
    D1 --> D2[Fast R-CNN]
    D2 --> D3[Faster R-CNN]
    D3 --> D4[FPN]
    D4 --> D5[Mask R-CNN]

    C --> C3[One-stage detectors]

    C3 --> E2[YOLO]

    C --> C4[Anchor-free]
    C4 --> F1[FCOS]

    C --> C5[Transformer detection]
    C5 --> G1[DETR]

    B4 --> H[Segmentation]

화살표는 개념적 발전 순서(A가 B의 문제의식/기반이 됨)이지, 실제 논문 인용 관계와 완전히 같지는 않다.

🔷 2. Low-level Segmentation / Region Proposal

CNN이 대중화되기 전, “물체가 있을 법한 영역"을 먼저 좁히기 위해 쓰이던 방식들.

방법핵심 아이디어문서논문
Efficient Graph-Based Segmentation픽셀을 그래프로 보고 유사도 기준으로 영역을 병합문서IJCV 2004 (PDF)
Selective Search위 저수준 분할을 여러 스케일로 수행 후 계층적으로 병합해 region proposal 생성문서IJCV 2013

🔷 3. Backbone Evolution (특징 추출기의 발전)

이미지를 벡터/feature map으로 바꾸는 Backbone 자체의 발전 흐름. 객체 탐지·분할 모델들은 대부분 이 중 하나를 feature extractor로 가져다 쓴다.

연도모델핵심 기여문서논문
1998LeNet-5최초의 실용 CNN (손글씨 인식)— (CNN 문서 §10 참고)Proc. IEEE 1998
-CNN (개념)합성곱·풀링·Flatten+FC의 기본 원리문서—
2012AlexNetReLU·Dropout·GPU 학습 도입, ImageNet 우승 → 딥러닝 붐 시작문서NeurIPS 2012
2014VGG$3\times3$ 필터만 깊게 쌓는 단순·균일 구조문서 (작성 중)arXiv:1409.1556
2014GoogLeNet / Inception다양한 크기 필터를 병렬로, GAP로 분류 헤드 대체문서 없음arXiv:1409.4842
2015ResNetResidual(skip) connection으로 100층 이상 학습 가능문서 (작성 중)arXiv:1512.03385
2019EfficientNet깊이·너비·해상도를 동시에 조절하는 Compound Scaling문서 없음arXiv:1905.11946

🔷 4. Object Detection

4.1 Classical / Two-stage

Region proposal을 먼저 뽑고, 각 후보에 대해 분류/회귀를 수행하는 방식.

모델핵심 기여문서논문
OverFeat (2013)Sliding window 기반, CNN으로 분류+검출 동시 수행문서arXiv:1312.6229
R-CNN (2014)Selective Search + CNN(AlexNet) feature + SVM 분류문서arXiv:1311.2524
Fast R-CNN (2015)ROI Pooling으로 이미지당 CNN 1회만 수행, Multi-task loss문서arXiv:1504.08083
Faster R-CNN (2015)RPN 도입으로 Selective Search(느림) 제거문서arXiv:1506.01497
FPN (2017)여러 스케일의 feature map을 피라미드로 결합, 작은 물체 탐지 개선문서 없음arXiv:1612.03144
Mask R-CNN (2017)Faster R-CNN + Mask Head, ROI Align으로 Instance Segmentation문서 (보완 필요)arXiv:1703.06870

4.2 One-stage

Region proposal 단계 없이 이미지 전체에서 한 번에 클래스+박스를 예측 → 빠름.

  • SSD (2016) — arXiv:1512.02325 , YOLO (2016) — arXiv:1506.02640 . 문서 없음

4.3 Improvement

  • RetinaNet (2017) — Focal Loss로 One-stage의 클래스 불균형(class imbalance) 문제 해결. 문서 없음. arXiv:1708.02002

4.4 Anchor-free

  • FCOS (2019) — Anchor box 없이 픽셀 단위로 직접 회귀. 문서 없음. arXiv:1904.01355

4.5 Transformer-based

  • DETR (2020) — Transformer로 anchor/NMS 없이 집합 예측(set prediction)으로 검출. 문서 없음. arXiv:2005.12872 . 기반 개념은 Transformer(Attention Is All You Need) 참고.

🔷 5. Segmentation

모델핵심 기여문서논문
U-Net (2015)Encoder-Decoder + skip connection, 의료 영상 분할에 강함문서 없음arXiv:1505.04597
DeepLabAtrous(dilated) convolution으로 해상도 유지하며 넓은 수용영역 확보문서 없음arXiv:1606.00915
Mask R-CNN§4.1 참고 (Instance Segmentation)문서 (보완 필요)arXiv:1703.06870

Amodal Segmentation (가려진 부분까지 포함한 전체 모양 예측) — Mask R-CNN 계열에서 파생된 별도 갈래. 2016년 문제 정의부터 2026년 SAM 기반 open-world 확장까지의 핵심 논문 7개는 Amodal Segmentation 개요 참고.

🔷 6. Modern Vision / Foundation Models

모델핵심 기여문서논문
ViT (2020)이미지를 patch로 잘라 Transformer에 그대로 입력, CNN 없이 분류문서 (작성 중)arXiv:2010.11929
Swin Transformer (2021)Window 기반 attention으로 ViT의 연산량 문제 완화, 계층적 feature map문서 없음arXiv:2103.14030
EfficientFormer (2022)실측 지연시간 기준으로 ViT의 병목(patch embed·reshape·LN) 제거 → MobileNet 속도의 순수 트랜스포머문서arXiv:2206.01191
SAM (2023)프롬프트(점/박스) 기반 범용 Segmentation 파운데이션 모델문서 없음arXiv:2304.02643

ViT 계열은 Transformer(Attention Is All You Need) 의 self-attention 개념을 이미지에 적용한 것이므로, 먼저 읽어두면 이해가 빠르다.

🔷 9. Key Axes to Understand

  • Region proposal vs sliding window
  • Two-stage vs One-stage detection
  • Anchor-based vs Anchor-free
  • CNN vs Transformer
  • Semantic vs Instance segmentation
  • Multi-scale feature (FPN)
  • Class imbalance (Focal Loss)
