2.AlexNet

AlexNet (2012)

📄 논문: ImageNet Classification with Deep Convolutional Neural Networks — Krizhevsky, Sutskever & Hinton, NeurIPS 2012

Krizhevsky, Sutskever, Hinton이 발표한 CNN. ILSVRC 2012(ImageNet 대회)에서 top-5 에러율 **15.3%**로 2위(26.2%)를 압도적으로 이기며 우승했다. “딥러닝이 실제로 통한다"는 것을 대규모 실전 데이터로 증명한 첫 사례로, 이후 VGG ·GoogLeNet·ResNet 등으로 이어지는 딥러닝 붐의 시발점이 된 모델이다.

CNN 의 기본 개념(합성곱, 풀링, Flatten+FC)을 먼저 이해하고 오면 이 문서를 읽기 수월하다.

🔷 1. 등장 배경 — 왜 AlexNet이 중요한가

2012년 이전까지 이미지 인식은 SIFT, HOG 같은 사람이 직접 설계한 특징(hand-crafted feature) + SVM 조합이 주류였고, ILSVRC 최고 성적도 top-5 에러 26%대에 머물러 있었다.

CNN 자체는 1998년 LeNet-5부터 존재했지만 대중화되지 못했는데, 이유는 크게 두 가지였다.

걸림돌내용
연산량 부족대규모 CNN을 학습시킬 만한 컴퓨팅 파워가 없었음
데이터 부족 → 과적합큰 모델을 학습시킬 만큼 크고 다양한 라벨 데이터셋이 없었음

AlexNet은 이 두 문제를 다음으로 정면 돌파했다.

  • 데이터: ImageNet(1000개 클래스, 약 120만 장의 학습 이미지) 사용
  • 연산: GPU(NVIDIA GTX 580, 3GB 메모리 2장) 병렬 학습 도입
  • 과적합 방지: Dropout, 데이터 증강(Data Augmentation) 등 정규화 기법 적극 도입

즉 AlexNet의 성공은 “새로운 이론"이 아니라, 깊은 CNN + 대용량 데이터 + GPU 학습 + 정규화 기법을 실전 스케일로 처음 결합해낸 엔지니어링의 승리에 가깝다.

🔷 2. 전체 구조 개요

5개의 Convolution Layer + 3개의 FC Layer, 총 8개의 학습 가능한 층으로 구성된다. (Pooling·정규화 층은 파라미터가 없어 층수에서 제외)

  • 입력: $224\times224\times3$ (RGB) — 단, 실제 출력 크기 계산이 맞으려면 $227\times227\times3$ 이어야 함 (논문 원문의 잘 알려진 오탈자. 아래 §3에서 $227$ 기준으로 계산)
  • 파라미터: 약 6,200만 개
  • 뉴런 수: 약 65만 개
flowchart LR
    IN["입력<br/>227×227×3"] --> C1["Conv1<br/>11×11, 96, s4"] --> R1["ReLU+LRN"] --> P1["MaxPool<br/>3×3, s2"]
    P1 --> C2["Conv2<br/>5×5, 256"] --> R2["ReLU+LRN"] --> P2["MaxPool<br/>3×3, s2"]
    P2 --> C3["Conv3<br/>3×3, 384"] --> R3["ReLU"]
    R3 --> C4["Conv4<br/>3×3, 384"] --> R4["ReLU"]
    R4 --> C5["Conv5<br/>3×3, 256"] --> R5["ReLU"] --> P3["MaxPool<br/>3×3, s2"]
    P3 --> FL["Flatten<br/>6×6×256=9216"]
    FL --> F6["FC6<br/>4096"] --> D1["ReLU+Dropout"]
    D1 --> F7["FC7<br/>4096"] --> D2["ReLU+Dropout"]
    D2 --> F8["FC8<br/>1000"] --> SM["Softmax"]

Conv1Conv5는 특징 추출부, FC6FC8은 분류부로 CNN 전체 구조 와 동일한 큰 그림을 따른다.

📌 2-GPU 분할 구조 (AlexNet의 상징적인 특징)

당시 GPU(GTX 580) 메모리가 3GB로 한 장에 전체 모델이 올라가지 않아, 저자들은 네트워크를 2개의 GPU에 절반씩 나눠 학습시켰다. 이는 알고리즘적 아이디어가 아니라 하드웨어 제약이 낳은 설계다.

  • Conv2, Conv4, Conv5는 같은 GPU 안의 feature map끼리만 연결(채널을 반씩 나눠 독립적으로 처리)
  • Conv3만 예외적으로 양쪽 GPU의 feature map을 모두 입력받는다 (두 GPU 간 통신은 이 지점 하나뿐 → 통신 비용 최소화)
  • 오늘날 GPU는 메모리가 충분하므로, 최신 구현체들은 이 분할 없이 하나의 GPU에서 전체 채널을 그대로 연결한 버전으로 재현하는 경우가 많다.

🔷 3. 레이어별 상세 (입출력 크기 계산)

CNN 출력 크기 공식 $O = \lfloor (N+2P-F)/S \rfloor + 1$ 을 그대로 적용한다. (아래는 2-GPU 분할을 무시하고 전체 채널 기준으로 계산 — 채널 수 자체는 분할 여부와 무관)

🧮 파라미터 수 계산 예시

CNN §8 공식 $\text{Params} = (F\times F\times C_{in}+1)\times C_{out}$ 을 적용하면:

\[\text{Conv1} = (11\times11\times3 + 1)\times 96 = 34{,}944\]
\[\text{FC6} = (9216 + 1)\times 4096 \approx 37{,}750{,}000\]

FC6 하나의 파라미터 수가 Conv1~Conv5 전체(약 230만 개)보다 훨씬 크다. Flatten 직후의 FC layer가 파라미터 대부분을 차지하는 구조적 특징은 VGG 에서도 동일하게 나타나며, 이후 Global Average Pooling 이 등장하는 배경이 된다. 전체 파라미터는 약 6,200만 개.

🔷 4. 핵심 기여 / 혁신 포인트

AlexNet이 CNN 이론 자체를 새로 만든 것은 아니지만, 아래 6가지를 실전 규모에서 처음으로 함께 입증했다.

① ReLU 활성화 함수

기존 CNN들은 Sigmoid /Tanh를 사용했는데, 이는 입력이 커지면 기울기가 0에 가까워지는 포화(saturation) 문제가 있어 학습이 느렸다.

AlexNet은 ReLU $f(x)=\max(0,x)$ 를 사용해 동일한 에러율 도달까지 Tanh 대비 약 6배 빠르게 수렴함을 실험으로 보였다. 이후 거의 모든 CNN의 기본 활성화 함수가 되었다.

② Overlapping Pooling

일반적인 풀링은 stride $S$ = 커널 크기 $F$ 로 영역이 겹치지 않게 설계하지만, AlexNet은 $F=3, S=2$ 로 커널이 서로 겹치도록(overlap) 풀링했다.

  • 효과: top-1/top-5 에러를 각각 0.4%p/0.3%p 감소시키고, 약간의 과적합 억제 효과도 관찰됨

③ Local Response Normalization (LRN)

생물학적 뉴런의 측면 억제(lateral inhibition) — 강하게 활성화된 뉴런이 주변 뉴런의 반응을 억제하는 현상 — 에서 착안한 정규화 기법. 같은 위치 $(x,y)$에서 인접한 채널끼리 정규화한다.

\[b^{i}_{x,y} = \dfrac{a^{i}_{x,y}}{\left(k + \alpha \sum_{j=\max(0,i-n/2)}^{\min(N-1,i+n/2)} \left(a^{j}_{x,y}\right)^2\right)^{\beta}}\]

논문에서 사용한 값: $k=2,\ n=5,\ \alpha=10^{-4},\ \beta=0.75$. Conv1, Conv2 이후에 적용되어 top-1/top-5 에러를 각각 1.4%p/1.2%p 낮췄다고 보고됨.

⚠️ 이후 VGG 논문 등에서 LRN이 실제로는 정확도 향상에 거의 기여하지 않고 연산·메모리만 늘린다는 것이 밝혀져 폐기되었다. 현재는 Batch Normalization 등으로 대체되어, 최신 아키텍처에서 LRN을 보기는 어렵다.

④ Dropout

FC6, FC7에 확률 0.5로 적용. 학습 시 매 forward pass마다 각 뉴런을 랜덤하게 꺼서(출력을 0으로 만들어) 특정 뉴런 조합에 과도하게 의존(co-adaptation)하는 것을 막는다.

  • 직관: 매번 다른 부분망(sub-network)을 학습시키는 것과 같아, 여러 모델을 암묵적으로 앙상블하는 효과
  • 테스트 시에는 모든 뉴런을 사용하되, 학습 때 꺼졌던 비율만큼 출력을 스케일링해 학습/추론 시 기대값을 맞춘다
  • 대신 수렴에 필요한 반복 횟수가 약 2배로 늘어난다는 트레이드오프가 있음

⑤ 데이터 증강 (Data Augmentation)

라벨 데이터가 있어도 6,000만 파라미터 모델은 과적합되기 쉬워, 레이블은 그대로 두고 이미지만 변형해 데이터를 늘렸다.

기법방법
Crop + 수평 뒤집기$256\times256$ 원본에서 $224\times224$ 패치를 랜덤 위치로 추출 + 좌우 반전 → 이론상 데이터 약 2048배 증강 효과
PCA Color Augmentation학습셋 전체 RGB 픽셀 값에 PCA를 수행, 주성분 방향으로 색상값을 랜덤하게 미세 조정 → 조명/색상 변화에 강건해짐

⑥ GPU 병렬 학습

위 §2의 2-GPU 분할 구조. 순수 알고리즘 기여는 아니지만, “딥러닝은 GPU로 학습한다"는 표준을 확립한 실용적 기여로 평가받는다.

🔷 7. 한계점

  • Flatten → FC 구조의 파라미터 폭증: FC6 하나가 전체 conv layer 파라미터 총합을 넘어섬 (§3 참고). 이 문제는 이후 Global Average Pooling 으로 해결된다.
  • LRN의 실효성 부족: §4-③에서 설명했듯 이후 연구에서 효과가 미미함이 밝혀져 폐기됨.
  • 큰 필터($11\times11$, $5\times5$): 한 번에 넓은 영역을 보지만 파라미터 대비 비효율적. VGG 는 $3\times3$ 필터를 깊게 쌓는 것이 같은 수용영역(receptive field) 을 더 적은 파라미터로 얻을 수 있음을 보여 이 설계를 대체했다.
  • 2-GPU 분할: 순수 하드웨어 메모리 제약에 따른 설계라, 메모리가 넉넉한 현대 GPU 환경에서는 불필요한 구조.

🔷 8. 의의 (Legacy)

  • ImageNet 우승으로 “깊은 CNN + GPU + 대용량 데이터” 조합이 실제로 통한다는 것을 최초로 실증 → 이후 학계·산업계 전반의 딥러닝 붐을 촉발.
  • VGG , GoogLeNet, ResNet 등 후속 Backbone 아키텍처 연구가 폭발적으로 이어짐.
  • 객체 탐지 분야에서도 초기 R-CNN 이 region proposal마다 특징을 추출하는 CNN으로 AlexNet을 그대로 채택했다.
  • ReLU, Dropout, 데이터 증강 등은 지금도 대부분의 딥러닝 모델에서 기본값처럼 쓰이는 표준 구성 요소가 되었다.
