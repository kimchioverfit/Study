    Learning to See the Invisible (ORCNN)

    📄 논문: Learning to See the Invisible: End-to-End Trainable Amodal Instance Segmentation — Follmann et al., WACV 2019

    Patrick Follmann et al., WACV 2019. 결론부터 아주 쉽게: "Mask R-CNN 에 예측 브랜치 몇 개만 더 붙여서, 사진 한 장 넣으면 한 번에 ‘보이는 부분’, ‘가려진 부분’, ‘전체 모양’ 세 가지 마스크를 동시에 뱉어내는 구조를 만든 논문. 앞선 두 논문이 “문제 정의"와 “데이터셋"에 집중했다면, 이 논문은 처음으로 실용적으로 갖다 쓸 수 있는 end-to-end 모델을 내놓았음.

    전체 계보 속 위치는 Amodal Segmentation 개요 참고. 이 구조는 일반적인 Mask R-CNN 기반 instance segmentation 구현과 가장 유사한 형태라, Mask R-CNN을 다뤄본 적이 있다면 가장 친숙하게 느껴질 논문임.

    1. 이 논문 이전까지의 아쉬운 점

    • Li & Malik(2016) : 문제는 정의했지만 실전에 바로 쓰기엔 구조가 투박함
    • Zhu et al.(2017) : COCOA라는 좋은 데이터셋은 만들었지만, “이 데이터로 어떤 모델 구조를 학습시켜야 하는가"는 별개 문제로 남아 있었음

    즉 “제대로 된 정답 데이터가 생겼으니, 이걸로 실제로 쓸 만한 모델을 학습시켜보자” 가 이 논문의 동기임.

    2. 핵심 아이디어 — Mask R-CNN에 브랜치 추가

    Mask R-CNN 은 원래 물체마다 박스(box) + 클래스(class) + 마스크(mask) 세 가지를 예측하는 구조임. ORCNN은 여기에 마스크 예측 부분을 확장해서 한 물체당 다음 세 종류의 마스크를 동시에 뱉게 만듦.

                              ┌─→ Visible mask  (눈에 보이는 부분만)
Mask R-CNN 기존 구조 ──▶ ROI ─┼─→ Invisible mask (가려서 안 보이는 부분)
   (박스+클래스는 그대로)    └─→ Amodal mask  (visible + invisible = 물체의 전체 모양)
    • Amodal mask = Visible mask ∪ Invisible mask — 전체 모양은 결국 “보이는 부분"과 “안 보이는 부분"을 합친 것이라는 아주 직관적인 관계로 정의됨
    • 세 마스크를 한 번의 forward pass로 동시에 예측 — Li&Malik의 방식처럼 별도의 우회 학습 절차가 필요 없음. “end-to-end trainable"이라는 표현이 여기서 나옴

    3. 왜 이게 “실용적"인가

    • 기존 Mask R-CNN 파이프라인(백본 → RPN → ROI Head)을 거의 그대로 재사용하고, 마스크 헤드만 세 갈래로 늘린 것이라 구현·학습 난이도가 낮음
    • 실무에서 Mask R-CNN을 이미 써봤다면 구조를 이해하고 갖다 쓰기 가장 쉬운 amodal 모델
    • COCOA 데이터셋에서 기존 baseline(= Li&Malik 방식)보다 큰 폭으로 성능을 앞섬

    4. 추가 기여 — 새 데이터셋 2종

    • D2S amodal: 산업/제품 이미지 도메인의 amodal 데이터셋
    • COCOA cls: COCOA를 클래스 라벨까지 포함해 정리한 버전

    COCOA가 처음엔 “클래스 구분 없이 전경/배경” 수준이었다면, 후속 데이터셋들은 실제 카테고리(사람, 자동차 등)별로 정리되며 점점 실전 벤치마크에 가까워짐.

    5. 의의와 한계

    의의: “brain-storming 수준의 아이디어"에서 “Mask R-CNN 위에 브랜치 붙이면 바로 쓸 수 있는 실용적 구조"로 분야를 한 단계 끌어올렸음.

    한계: 여전히 이미지 하나, 카테고리가 고정된 닫힌 학습 데이터(closed-set) 범위 안에서만 잘 동작함 — 학습 때 못 본 물체 종류나 상황엔 약함. 이 한계는 계보의 마지막 논문 Amodal SAM(2026) 이 정면으로 다룸. 한편 자율주행처럼 훨씬 대규모·고위험 상황에서의 amodal 학습은 KINS 데이터셋(Qi et al., 2019) 이 이어받음.
