1.Amodal Instance Segmentation

Amodal Instance Segmentation

📄 논문: Amodal Instance Segmentation — Ke Li & Jitendra Malik, ECCV 2016

Ke Li & Jitendra Malik, ECCV 2016. 결론부터 아주 쉽게: “가려진 부분까지 포함해서 물체의 전체 모양을 예측하자"는 문제(amodal instance segmentation) 자체를 처음으로 명확히 정의하고, 정답 라벨이 없는 상황에서도 학습시킬 수 있는 기발한 훈련법을 제시한 논문. Amodal segmentation 분야의 사실상 출발점이다.

전체 계보 속 위치는 Amodal Segmentation 개요 참고.

1. 먼저 — “Amodal"이 뭔가

일반적인 instance segmentation(예: Mask R-CNN )은 이미지에서 눈에 보이는 픽셀만 마스크로 표시한다.

사진: 자동차 뒤에 절반 가려진 강아지

[일반 segmentation이 뱉는 마스크]      [사람이 상상하는 강아지의 진짜 모양]
     ▓▓▓ (보이는 뒷다리, 꼬리만)          ▓▓▓▓▓▓▓ (온전한 강아지 한 마리)

사람은 절반만 보여도 “원래는 저런 통짜 모양의 강아지겠구나"를 바로 압니다. 이 논문은 “모델도 이걸 하게 만들자” 는 목표를 “amodal instance segmentation"이라는 이름으로 처음 학술적으로 정식화했다.

  • modal segmentation: 보이는 부분만 (기존 방식)
  • amodal segmentation: 안 보이는 부분까지 포함한 전체 모양 (이 논문이 제안하는 문제)

2. 왜 어려운가 — 정답이 없다

이게 왜 지금까지 안 풀렸냐면: 학습에 쓸 정답 자체가 없기 때문이다.

  • COCO 같은 표준 데이터셋은 사람이 “보이는 픽셀"만 라벨링해뒀다 — 가려진 부분의 “진짜 모양"은 애초에 라벨링된 적이 없다 (사람도 안 보이는 걸 정확히 라벨링하기 어렵다)
  • 즉 “이 강아지의 진짜 전체 모양은 이거다"라는 지도학습(supervised learning)용 정답(ground truth)이 세상에 존재하지 않는 상황에서 학습을 시켜야 한다

3. 이 논문의 해법 — 있는 데이터로 정답을 “만들어낸다”

핵심 아이디어는 기존의 modal(보이는 부분만) 마스크 라벨을 재활용해서, 인위적으로 “가려진 상황"을 만들어 학습 쌍을 스스로 생성하는 것이다.

① COCO에는 "안 가려진 상태의 강아지 전체 마스크"가 이미 있다 (원래는 modal 라벨이지만,
   안 가려진 물체라면 이 마스크 자체가 곧 "진짜 전체 모양"이기도 하다)

② 이 강아지 마스크 위에, 다른 물체(예: 자동차)의 마스크를 인위적으로 겹쳐서
   "일부러 가린 것"처럼 만든 입력을 만든다

   [원본: 안 가려진 강아지 전체]  +  [인위적으로 덮은 자동차 모양]
              ↓
   [입력: 절반 가려진 것처럼 보이는 강아지]  →  모델 예측 → [목표: 원본 강아지 전체 마스크]

③ "가려진 입력을 보고, 안 가려졌을 때의 원본 전체 마스크를 맞춰라"로 학습시킨다
  • 이렇게 하면 실제 amodal 라벨을 사람이 새로 만들 필요 없이, 기존 modal 라벨만으로 훈련 쌍을 무한히 생성할 수 있다
  • 논문 표현으로는 “표준 modal instance segmentation 라벨만 사용해서 문제를 우회했다”

4. 의의와 한계

의의:

  • amodal instance segmentation이라는 문제 자체를 처음 명확히 정의 — 이후 모든 후속 연구(이 계보의 나머지 6개 논문 포함)의 출발점이 됐다
  • “정답 라벨이 없는 문제를, 있는 라벨을 인위적으로 가공해서 우회한다"는 아이디어 자체는 이후 Zhan et al. (2020) 의 self-supervised 학습법으로 훨씬 정교하게 발전한다

한계:

  • 어디까지나 인위적으로 합성한 가림을 기준으로 학습한 것이라, 실제 사진 속의 자연스러운 가림 패턴과는 차이가 있을 수 있다
  • “진짜 사람이 라벨링한 amodal 정답"으로 평가하는 벤치마크가 없었다 — 이 문제는 바로 다음 논문 Semantic Amodal Segmentation (Zhu et al., 2017) 의 COCOA 데이터셋이 해결한다
