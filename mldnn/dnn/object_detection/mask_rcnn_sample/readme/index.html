    Mask R-CNN 학습 코드 구조

    Mask R-CNN 학습 코드 구조 익히기

    Mask R-CNN 학습 파이프라인의 구성 요소와 순서를 학습하기 위한 샘플 코드임. 성능이 아니라 “각 단계가 왜 필요하고 무엇을 하는지"를 이해하는 데 초점을 맞췄음.

    1. 빠른 시작

    pip install -r requirements.txt
    python make_dummy_dataset.py --num-images 60
    python train.py --epochs 3 --batch-size 2

    첫 실행 시 COCO 사전학습 가중치(약 170MB)를 자동으로 내려받음. 오프라인 환경이라면 --no-pretrained 를 붙이면 됨 (학습은 되지만 성능은 낮음).

    학습이 끝나면 outputs/ 에 체크포인트, 학습 기록, GT/예측 시각화 이미지가 저장됨.

    추론만 따로 해보려면:

    python predict.py --checkpoint outputs/best_model.pth --input data/images

    2. 파일 구성 (읽는 순서 추천)

    순서파일역할여기서 배우는 것
    1config.py모든 하이퍼파라미터 집중 관리실험 재현성, 설정 분리
    2make_dummy_dataset.py합성 데이터 생성인스턴스 마스크 형식(ID 맵)
    3dataset.py파일 → (image, target) 변환Mask R-CNN의 target 규약
    4transforms.py데이터 증강박스·마스크를 이미지와 함께 변형
    5model.py모델 생성, head 교체전이학습, 모델 구조
    6engine.py학습/평가 1 epochloss dict 반환 구조, mAP 계산
    7train.py전체 조립파이프라인 순서
    8visualize.py결과 시각화디버깅 습관
    9predict.py추론 전용 경로배포 시 필요한 최소 코드
    —utils.py시드, 로깅, 체크포인트, collate_fn보조 도구

    3. 전체 학습 흐름

    설정 로드 / 시드 고정
        ↓
Dataset  (이미지 + 인스턴스 마스크 → boxes / labels / masks)
        ↓
Transforms  (이미지와 target을 함께 증강)
        ↓
DataLoader  (collate_fn 으로 가변 크기 샘플 묶기)
        ↓
Model  (ResNet50-FPN backbone + RPN + RoIAlign + Box/Mask head)
        ↓
반복: forward → 5개 loss 합산 → backward → optimizer.step()
        ↓
Validation (loss) → LR scheduler step → Checkpoint 저장
        ↓
최종 평가 (mAP) → 예측 결과 시각화

    4. 꼭 기억할 4가지

    (1) 모델이 손실을 직접 계산함

    torchvision detection 모델은 모드에 따라 반환값이 다름.

    model.train()
loss_dict = model(images, targets)   # dict of 5 losses  ← 예측이 아님!

model.eval()
outputs = model(images)              # list of predictions  ← loss가 아님!

    criterion = nn.CrossEntropyLoss() 같은 코드가 없는 이유임.

    (2) 5개의 손실

    손실어디서의미
    loss_objectnessRPN후보 영역에 객체가 있는가
    loss_rpn_box_regRPN후보 박스 좌표 보정
    loss_classifierBox head객체의 클래스 분류
    loss_box_regBox head최종 박스 좌표 회귀
    loss_maskMask head픽셀 단위 이진 마스크

    최종 loss는 이 다섯 개의 합임 (engine.py의 sum(loss_dict.values())).

    (3) target 형식

    target = {
    "boxes":    FloatTensor[N, 4],      # (x1, y1, x2, y2) 절대 픽셀 좌표
    "labels":   Int64Tensor[N],         # 1부터 시작 (0은 배경 전용)
    "masks":    UInt8Tensor[N, H, W],   # 객체별 이진 마스크
    "image_id": Int64Tensor[1],
    "area":     FloatTensor[N],
    "iscrowd":  Int64Tensor[N],
}
    • 라벨 0은 배경 전용이므로 실제 클래스는 1부터 매김.
    • 넓이가 0인 박스(x2 <= x1)가 하나라도 있으면 학습이 NaN으로 터짐. dataset.py에서 이를 걸러 내고 있음.

    (4) collate_fn이 반드시 필요함

    이미지 크기와 객체 수가 샘플마다 다르므로 기본 collate의 torch.stack()이 실패함. 튜플로 그대로 묶어 넘기고, 크기 맞춤은 모델 내부 GeneralizedRCNNTransform이 처리함.

    5. 자주 만나는 문제

    증상원인해결
    loss가 NaNlr이 너무 큼 / 넓이 0인 박스--lr 0.001, warm-up 늘리기
    CUDA out of memory배치가 큼 / 이미지가 큼--batch-size 1, --amp
    stack expects each tensor to be equal sizecollate_fn 미지정DataLoader에 collate_fn=collate_fn
    학습은 되는데 mAP가 0라벨을 0부터 매김클래스 인덱스를 1부터 시작
    Windows에서 DataLoader 멈춤num_workers>0 + 가드 없음if __name__ == "__main__": 확인

    6. 자신의 데이터로 바꾸려면

    1. 데이터를 아래 구조로 준비함.
      data/
  images/  0000.png ...
  masks/   0000.png ...   ← 픽셀값이 인스턴스 ID (0=배경, 1,2,3...)
  labels/  0000.txt ...   ← 인스턴스 순서대로 클래스 인덱스 (선택)
    2. config.py의 num_classes(배경 포함)와 class_names를 수정함.
    3. COCO JSON 형식을 쓰고 있다면 dataset.py의 __getitem__만 교체하면 됨. 나머지 모듈은 그대로 재사용됨 — 그것이 모듈화의 목적임.
