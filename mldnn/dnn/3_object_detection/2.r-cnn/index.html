2.R CNN

R-CNN (2014)

📄 논문: Rich feature hierarchies for accurate object detection and semantic segmentation — Girshick et al., CVPR 2014

Regions with CNN features — Selective Search 로 뽑은 후보 영역마다 CNN 으로 특징을 추출해 객체를 탐지한 모델. 손으로 설계한 특징(HOG 등)에 의존하던 기존 detection을 CNN 기반으로 전환시킨 출발점으로, 이후 Fast R-CNN → Faster R-CNN → Mask R-CNN 으로 이어지는 R-CNN 계열의 시작이다.

🔷 1. 핵심 아이디어

  1. Selective Search 로 객체가 있을 법한 region proposal 약 2000개를 생성.
  2. 각 proposal을 고정 크기로 warping한 뒤 CNN(당시 AlexNet )에 넣어 feature 추출.
  3. 클래스별 SVM으로 분류하고, Bounding Box Regression으로 박스 위치를 보정.
  4. NMS로 겹치는 박스를 제거해 최종 detection 완성.
flowchart LR
    IN["입력 이미지"] --> SS["Selective Search<br/>~2000 proposals"]
    SS --> W["Warp<br/>227×227로 리사이즈"]
    W --> CNN["CNN (AlexNet)<br/>proposal마다 forward"]
    CNN --> F["4096-d feature vector"]
    F --> SVM["클래스별 SVM<br/>분류"]
    F --> REG["Bbox Regression<br/>위치 보정"]
    SVM --> NMS["NMS<br/>중복 박스 제거"]
    REG --> NMS
    NMS --> OUT["최종 박스 + 클래스"]

이름 그대로 Region proposal + CNN의 조합이 핵심이다.

🔷 2. Region Proposal (Selective Search)

CNN에 넣기 전에 “물체가 있을 법한 영역"을 먼저 좁힌다. 상세 알고리즘은 Selective Search 문서 참고.

  1. 원본 이미지에서 각 Object가 개별 영역에 담기도록 수많은 작은 영역을 생성 (Object를 놓치지 않기 위한 Oversegmentation).

  2. 유사도가 높은 영역들을 하나로 병합한다.

    • $R = \{r_1, ..., r_n\}$ — 초기 segmentation으로 나온 n개의 후보 영역
    • $S$ — 영역들 사이의 유사도 집합
    • 색상·무늬·크기·형태를 고려해 각 영역 쌍의 유사도를 계산
    • 유사도가 가장 높은 $r_i, r_j$를 합쳐 새 영역 $r_t$ 생성 → 관련 유사도를 $S$에서 삭제하고 $r_t$에 대한 유사도를 다시 계산해 추가

  3. 위 과정을 반복해 최종 후보 영역(약 2000개)을 도출.

이렇게 얻은 후보 영역들에 대해 CNN으로 분류 + 박스 보정을 수행하는 것이 R-CNN이다. Selective Search는 학습되지 않는 고정 알고리즘이라는 점이 뒤에서 한계로 작용한다(§7).

2000개 proposal을 CNN에 통과시키기

Selective Search로 뽑은 약 2000개의 region proposal을 하나씩 CNN에 넣는다. proposal마다 크기·비율이 제각각이므로, 각 영역을 먼저 CNN 입력 크기(227×227)로 warping한 뒤 CNN에 통과시켜 고정 길이 feature vector를 얻는다.

  • 이미지 1장 → proposal ~2000개 → CNN forward를 ~2000번 수행.
  • 각 proposal이 독립적으로 CNN을 통과하므로, 겹치는 영역의 연산이 중복된다.
  • 이렇게 얻은 feature를 다음 단계(§4)에서 SVM 분류 + Bbox Regression에 사용한다.

이 “proposal마다 따로 CNN을 돌리는” 구조가 R-CNN을 매우 느리게 만드는 핵심 원인이며(§7), 이후 Fast R-CNN 에서 이미지 전체를 한 번만 통과시키는 방식으로 개선된다.

🔷 3. CNN Feature 추출

§2에서 각 proposal을 warping 후 CNN에 통과시킨다고 했다. 이 CNN의 출력이 곧 고정 길이 feature vector(AlexNet 기준 4096-d) 이며, 여기서는 그 입력 처리 방식인 warping을 자세히 본다.

Warping (고정 크기 변형)

AlexNet 같은 CNN은 입력 크기가 227×227로 고정이므로 proposal을 강제 리사이즈해야 하는데, 이때 원래 종횡비를 무시하는 것이 특징이자 약점이다.

특징설명
방식원래 종횡비를 무시하고 정사각형으로 늘림 (aspect ratio 왜곡 발생)
문제점물체가 찌그러져 정보 손실. 이후 Fast R-CNN 의 ROI Pooling이 이 warping을 대체

🔷 4. 분류 & 위치 보정

추출한 feature vector를 두 갈래로 사용한다.

(1) 클래스별 SVM 분류

  • 클래스마다 이진 SVM(one-vs-rest) 을 따로 학습해, “이 영역이 클래스 C인가?“를 판단(class당 output unit 2개).
  • 2000개 proposal → 2000×4096 feature matrix가 각 SVM을 거쳐 class별 confidence score로 변환된다.
  • Softmax 대신 SVM을 쓴 이유: 논문 실험에서 SVM 쪽 mAP가 더 높았기 때문. 실제로 SVM 대신 Softmax를 쓰면 mAP가 54.2% → 50.9%로 하락했다(적은 positive 샘플에 SVM이 더 robust). 대신 학습 파이프라인이 분리되는 단점이 생긴다.

(2) Bounding Box Regression

  • SVM이 고른 박스는 위치가 부정확하므로, CNN feature로부터 박스 보정값 4개 $d_x, d_y, d_w, d_h$ 를 회귀해 위치·크기를 미세 조정한다.
  • proposal 박스 $\mathbf{p}=(p_x, p_y, p_w, p_h)$, 정답(GT) 박스 $\mathbf{g}=(g_x, g_y, g_w, g_h)$ 라 할 때, 예측 박스 $\hat{\mathbf{g}}$ 는 다음처럼 보정한다:
$$ \hat{g}_x = p_w\, d_x(\mathbf{p}) + p_x, \qquad \hat{g}_y = p_h\, d_y(\mathbf{p}) + p_y $$$$ \hat{g}_w = p_w\, \exp\!\big(d_w(\mathbf{p})\big), \qquad \hat{g}_h = p_h\, \exp\!\big(d_h(\mathbf{p})\big) $$
  • 중심 좌표 $(x,y)$ 는 폭·높이로 정규화한 이동량으로, 크기 $(w,h)$ 는 로그 스케일 비율로 회귀하는 것이 포인트다. 학습 target은:
$$ t_x = \frac{g_x - p_x}{p_w},\quad t_y = \frac{g_y - p_y}{p_h},\quad t_w = \log\frac{g_w}{p_w},\quad t_h = \log\frac{g_h}{p_h} $$
  • Loss는 target $t_i$ 와 예측 $d_i(\mathbf{p})$ 의 SSE + L2 정규화(논문 $\lambda = 1000$):
$$ \mathcal{L}_\text{reg} = \sum_{i \in \{x,y,w,h\}} \big(t_i - d_i(\mathbf{p})\big)^2 + \lambda \lVert \mathbf{w} \rVert^2 $$

  • 이 보정만으로도 VOC mAP가 수 % 상승한다.

(3) NMS (Non-Maximum Suppression)

같은 물체에 여러 박스가 겹쳐 잡히므로, 클래스별로:

  1. confidence score가 임계값(예: 0.5) 미만인 박스를 먼저 제거
  2. 남은 박스를 confidence 내림차순으로 정렬 후, 가장 높은 박스를 선택
  3. 그 박스와 IoU가 임계값(예: 0.3~0.4) 이상으로 겹치는 다른 박스들을 제거
  4. 남은 박스에 대해 2~3 반복

→ 물체 하나당 박스 하나만 남긴다.

🔷 5. 학습 방법 (다단계 파이프라인)

R-CNN은 한 번에 학습되지 않고 여러 단계로 따로 학습한다 — 이것이 대표적 단점이다.

단계내용
① 사전학습ImageNet 분류 로 CNN을 supervised pre-training
② Fine-tuningdetection 데이터로 CNN을 미세조정. GT와 IoU ≥ 0.5인 proposal을 positive, 나머지를 background로 라벨링. 마지막 layer는 N+1개(N개 class + 배경) output. mini-batch는 positive 32 + negative 96 = 128개로 구성
③ SVM 학습고정된 CNN feature 위에 클래스별 SVM 학습. positive는 GT 박스만, IoU < 0.3만 negative, 그 사이(0.3~1)는 무시. hard negative mining 적용
④ Bbox Regressorpool5 feature로 박스 보정 회귀 학습. IoU ≥ 0.6인 proposal만 positive로 사용

②의 fine-tuning은 데이터 확보를 위해 IoU ≥ 0.5를 positive로 느슨하게 잡아(약 30배 많은 학습 샘플) overfitting을 막는 반면, ③의 SVM은 GT만 positive로 엄격히 잡는다 — positive/negative 기준(IoU)이 단계마다 다른 점이 R-CNN의 복잡함을 보여준다. 게다가 추출한 feature를 디스크에 저장해가며 학습해 저장 공간·시간 부담이 크다.

Hard Negative Mining

배경(negative)이 객체(positive)보다 압도적으로 많은 class imbalance 상황에서, 모델이 False Positive로 잘못 판단한 배경 샘플을 모아 학습 데이터에 추가해 재학습한다. “헷갈리는 배경"을 집중적으로 학습시켜 오탐을 줄이는 기법이다.

🔷 6. 성능 & 의의

  • PASCAL VOC 2007에서 기존 최고 성능(DPM 등 hand-crafted feature 기반, mAP 약 33%)을 크게 뛰어넘어 mAP 약 54~58%(backbone을 VGG 로 바꾸면 66%까지) 달성.
  • “CNN feature가 detection에서도 압도적“임을 처음으로 실증 → 이후 detection 연구가 전부 CNN 기반으로 재편됨.
