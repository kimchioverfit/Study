Auto Encoding Variational Bayes

Auto-Encoding Variational Bayes (VAE)

📄 논문: Auto-Encoding Variational Bayes — Kingma & Welling, ICLR 2014

Kingma & Welling, 2013. VAE(Variational Autoencoder) 를 처음 제안한 논문. 결론부터 아주 쉽게: “압축했다가 복원하는 오토인코더인데, 압축한 결과를 딱 하나의 점이 아니라 ‘이 근처 어딘가’라는 확률 구름으로 만들어서 — 그 구름에서 아무 데나 찍어도 그럴듯한 새 데이터를 만들 수 있게 한 모델” 이다.

1. 먼저, 오토인코더(Autoencoder)부터

오토인코더는 두 부분으로 이루어진다.

입력(예: 고양이 사진) → [Encoder] → 압축된 벡터(z) → [Decoder] → 복원된 사진
  • Encoder: 큰 이미지를 작은 벡터 z로 압축 (예: 784차원 이미지 → 20차원 벡터)
  • Decoder: 그 작은 벡터를 다시 원래 이미지로 복원
  • 학습 목표는 단순하다: “입력과 복원 결과가 최대한 똑같게”

이 작은 벡터 z가 사는 공간을 잠재 공간(latent space) 이라 부른다. 잘 학습되면 이 공간엔 “고양이다움”, “표정”, “각도” 같은 의미가 압축되어 있다고 기대한다.

2. 그런데 일반 오토인코더로는 “새로운 것"을 못 만든다

여기서 하고 싶은 것: 잠재 공간에서 아무 점이나 하나 골라 Decoder에 넣으면 새로운 고양이 사진이 나오면 좋겠다. 이게 되면 “생성 모델"이 된다.

하지만 일반 오토인코더는 이게 잘 안 된다. 왜냐하면:

  • Encoder는 학습 데이터 각각을 잠재 공간의 딱 하나의 점으로만 찍어 넣는다
  • 학습은 “그 점들을 Decoder가 잘 복원하는지"만 신경 쓴다 — 점과 점 사이에 뭐가 있어야 하는지는 아무도 신경 쓰지 않는다
  • 그 결과 점들이 듬성듬성, 아무렇게나 흩어진다. 점과 점 사이의 빈 공간에서 하나 뽑아 Decoder에 넣으면 의미 없는 잡음이 나온다
일반 오토인코더의 잠재 공간 (점들이 듬성듬성, 사이는 보장이 없음)

     ●고양이1        ●강아지1
              (빈 공간 = 여기서 뽑으면 이상한 게 나옴)
         ●고양이2

VAE의 잠재 공간 (각 데이터가 '구름'을 만들고, 구름끼리 겹치며 매끈하게 이어짐)

    ░░●░░  ░░●░░
   ░░░░░░░░░░░░░░   ← 구름 사이 어디를 찍어도 그럴듯한 결과
    ░░●░░  ░░●░░

3. VAE의 핵심 아이디어 — 점 대신 “확률 구름”

VAE는 Encoder가 하나의 점을 뱉는 대신, 평균(μ)과 분산(σ²) 을 뱉게 만든다. 즉 “정확히 여기"가 아니라 “이 평균 근처, 이 정도 퍼짐으로 존재한다"는 확률분포를 출력한다.

입력 → [Encoder] → μ(평균), σ(표준편차)  →  z를 이 분포에서 샘플링  → [Decoder] → 복원

이렇게 하면 학습 중에 매번 z가 μ 주변에서 흔들리며 샘플링되므로, Decoder는 “정확히 이 점 하나"가 아니라 그 주변 전체를 잘 복원하도록 강제된다. 자연히 데이터들의 구름이 서로 겹치고 이어지면서 잠재 공간 전체가 매끈해진다 — 그래서 아무 점이나 찍어도 그럴듯한 출력이 나온다.

4. 학습시키는 두 가지 목표 (Loss)

VAE는 두 가지를 동시에 잘하도록 학습한다. 이걸 논문에서는 ELBO(Evidence Lower Bound) 를 최대화한다고 표현하는데, 풀어보면 다음 두 항의 균형이다.

$$\text{ELBO} = \underbrace{\mathbb{E}[\log p(x|z)]}_{\text{복원을 잘하기}} - \underbrace{D_{KL}(q(z|x) \,\|\, p(z))}_{\text{구름을 정돈하기}}$$
항쉬운 말안 하면 생기는 문제
복원 손실 (Reconstruction Loss)“압축했다가 풀었을 때 원본과 비슷해야 한다”이것만 있으면 일반 오토인코더와 같아짐 — 점들이 제멋대로 흩어짐
KL Divergence“각 데이터의 확률 구름이 표준정규분포(평균 0, 분산 1)에 가깝게, 너무 멀리 벗어나거나 너무 뾰족(사실상 점)해지지 말아라”이것만 있으면 모든 구름이 원점에 뭉쳐서 복원을 포기함

둘의 줄다리기가 핵심이다:

  • 복원 손실만 신경 쓰면 → Encoder가 σ를 거의 0으로 만들어 사실상 “점"으로 되돌아가려 한다 (일반 오토인코더로 퇴화)
  • KL 항이 이를 막는다 — “구름을 너무 뾰족하게 만들지 마라, 표준정규분포 크기 정도는 퍼져 있어라"라고 규제(regularize)한다
  • 그 결과 구름들이 적당히 퍼지고 서로 겹치면서, 잠재 공간 전체가 매끈하고 의미 있는 공간이 된다

5. Reparameterization Trick — 이 논문의 진짜 기여

“확률분포에서 샘플링한다"는 아이디어 자체는 간단하지만, 문제가 하나 있다. 샘플링(랜덤)은 미분이 안 되므로, 역전파(backpropagation)로 Encoder를 학습시킬 수가 없다.

이 논문이 제시한 해법이 reparameterization trick이다.

❌ 이렇게 샘플링하면 미분 불가:
z = sample from N(μ, σ²)          // μ, σ에서 랜덤 추출 — 이 과정 자체가 미분 안 됨

✅ 이렇게 바꾸면 미분 가능:
ε = sample from N(0, 1)            // 랜덤성을 별도의 고정 분포로 분리
z = μ + σ × ε                      // 이제 z는 μ, σ에 대해 완전히 미분 가능한 수식
  • 핵심은 “랜덤한 부분”(ε)과 “학습되는 부분”(μ, σ)을 분리한 것이다
  • ε은 그냥 표준정규분포에서 뽑은 고정된 노이즈 취급 — 여기엔 미분이 필요 없다
  • z = μ + σ × ε 이 수식은 순수하게 μ, σ에 대한 함수이므로 역전파가 그대로 통과한다
  • 이 트릭 덕분에 “확률분포를 학습하는 모델"을 일반적인 신경망 학습(경사하강법)으로 통째로 학습시킬 수 있게 됐다 — 이게 이 논문이 유명한 진짜 이유다

7. 참고 — 이후 발전

  • VAE의 “너무 매끈하게 만들려다 결과물이 흐릿(blurry)해진다"는 한계는 이후 GAN, Diffusion 모델 등이 다른 방식으로 접근하게 되는 동기가 된다
  • Encoder가 뱉는 (μ, σ)는 실무에서 보통 log(σ²)를 출력하도록 구현한다 — σ가 항상 양수여야 하는데 신경망 출력은 음수도 나올 수 있어서, log 공간에서 다루고 나중에 exp를 씌운다
