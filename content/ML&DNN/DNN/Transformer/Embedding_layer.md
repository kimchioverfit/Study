# Embedding Layer

### 임베딩 레이어란?

Token을 n Dimension으로 변환하는 과정. 

### 왜 필요할까?

컴퓨터는 문자열을 직접 이해하지 못하므로, 거리나 유사도 개념이 없어서 학습이 불가능하다.

이런 상황에서, 각 Token에 대한 ID를 이용하여 
key-value 구조로 Vector값을 갖게 하는 것. 

이걸 해줘야 Model 이 Token을 이해 가능.
```
"페페" 라는 Token ID : 1234
Value[1234] = [0.23, 0.17, ...] (weight들)
```
이런 식의 변환이라고 보면 된다.

임베딩 차원이 높을 수록 더욱 다양한 정보를 저장 가능하다.
