1. 컴파일/링크 단계

static 변수(전역/지역 정적 모두)는 **“정적 저장 기간(static storage duration)”**을 갖습니다.

즉, 컴파일러와 링커는 실행 파일을 만들 때 이 변수들을 **실행 파일의 데이터 섹션(.data/.bss)**에 자리를 잡아 둡니다.

따라서 메모리 공간은 이미 compile & link 시점에 확보돼 있는 셈.

2. 초기화 시점

C++ 표준은 정적 변수의 초기화를 두 단계로 나눕니다.

정적 초기화(static initialization)

상수로 초기화 가능한 경우: 실행 시작 전에 바로 값이 들어감

예: static int x = 5; → 실행 전에 바로 5로 세팅

동적 초기화(dynamic initialization)

생성자 호출이나 함수 호출이 필요한 경우: 실행 중에 최초로 초기화 코드가 실행됨

예: static std::string s("hello"); → 프로그램 시작 후 런타임에 생성자 호출

**지역 정적 변수(local static)**는 함수 안에 있더라도 “처음 그 함수에 진입할 때 단 한 번만” 초기화됩니다. (C++11 이후 스레드 안전 보장)
