# New 와 Malloc 비교 

| 구분         | `new` (C++)                          | `malloc` (C)                  |
| ---------- | ------------------------------------ | ----------------------------- |
| 언어         | C++ 전용                               | C 언어 (C++에서도 사용 가능)           |
| 반환 타입      | 요청한 타입의 포인터를 반환 → **형변환 불필요**        | `void*` 반환 → C++에선 **형변환 필요** |
| 생성자 호출     | **호출함** (객체 초기화)                     | 호출하지 않음                       |
| 소멸자 호출     | `delete` 시 호출됨                       | `free` 시 호출 안 됨               |
| 크기 지정      | 타입 크기 자동 계산                          | 직접 `sizeof`로 지정               |
| 예외 처리      | 메모리 부족 시 `std::bad_alloc` 예외 발생 (기본) | 메모리 부족 시 `NULL` 반환            |
| 연관 함수      | `delete`, `delete[]`                 | `free`                        |
| 오버로딩 가능 여부 | 가능 (`operator new` 재정의 가능)           | 불가능                           |
| 초기화        | `new int(5)`처럼 할당과 초기화 동시 가능         | 초기화 기능 없음 (직접 `memset` 등 사용)  |

### 결론

C++ 객체 생성 → new/delete 사용 (생성자·소멸자 자동 처리)

C 스타일 메모리 블록 → malloc/free 사용 (초기화·정리는 직접)

섞어서 쓰면 안 됨 (new ↔ free, malloc ↔ delete 혼용 금지)
