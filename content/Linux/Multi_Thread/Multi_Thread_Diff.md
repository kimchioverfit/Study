# Diff between POSIX & CPP standard

| 항목      | `std::thread`           | `pthread`              |
| ------- | ----------------------- | ---------------------- |
| 함수 시그니처 | `void func(int)`        | `void* func(void*)`    |
| 인자 전달   | 타입 안전 (직접 전달)           | `void*`로 변환 필요         |
| 자원 해제   | RAII (`join()` 깜빡하면 오류) | 수동 (`pthread_join` 필수) |
| 예외 처리   | 예외 전파 가능                | 예외 처리 불가 (C 스타일)       |

저수준에서 사용하려면 POSIX가 나음.

| 기능                 | std::thread | pthread |
| ------------------ | ----------- | ------- |
| CPU 바인딩 (Affinity) | ❌           | ✅       |
| 스택 사이즈 설정          | ❌           | ✅       |
| 스케줄 정책 설정          | ❌           | ✅       |
| 실시간 우선순위 설정        | ❌           | ✅       |
| NUMA 제어            | ❌           | ✅       |
| 동기화 세부제어 (`futex`) | ❌           | ✅       |
| POSIX 호환 시스템 통합    | 제한적         | 완전      |
