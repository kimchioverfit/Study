Min Heap Priority Queue

Min Heap & Priority Queue

힙(Heap) 은 “최솟값(또는 최댓값)을 O(1)에 조회하고, 삽입/삭제를 O(log N)에 처리"하는 완전 이진 트리 기반 자료구조. 우선순위 큐(Priority Queue) 는 이 힙으로 구현하는 것이 표준이다.

여기서의 힙은 자료구조 힙이다. malloc이 쓰는 메모리 영역 힙(Linux/Memory )과는 이름만 같고 무관하다.

1. 구조와 성질

Min Heap 성질: 모든 노드에 대해 부모 ≤ 자식. (Max Heap은 반대)

        1
      /   \
     3     2
    / \   / \
   7   4 5   9
  • 완전 이진 트리이므로 배열 하나로 표현 가능 — 포인터 없이 인덱스 계산만으로 이동
배열: [1, 3, 2, 7, 4, 5, 9]   (0-indexed)

parent(i) = (i - 1) / 2
left(i)   = 2*i + 1
right(i)  = 2*i + 2
  • 루트(arr[0])가 항상 최솟값 → 조회 O(1)
  • 힙은 “전체가 정렬된 상태"가 아니다. 보장은 오직 부모-자식 간 대소뿐 (형제끼리는 순서 없음)

2. 핵심 연산

2-1. push — sift-up, O(log N)

배열 끝에 넣고, 부모보다 작으면 계속 위로 교환한다.

push(0):  [1,3,2,7,4,5,9,0]  → 0을 7과 교환 → 3과 교환 → 1과 교환
결과:     [0,1,2,3,4,5,9,7]

2-2. pop — sift-down, O(log N)

루트를 꺼내고, 마지막 원소를 루트로 올린 뒤 두 자식 중 작은 쪽과 계속 아래로 교환한다.

#include <vector>

struct MinHeap {
    std::vector<int> a;

    void push(int x) {
        a.push_back(x);
        int i = (int)a.size() - 1;
        while (i > 0 && a[(i - 1) / 2] > a[i]) {   // 부모가 더 크면 교환
            std::swap(a[(i - 1) / 2], a[i]);
            i = (i - 1) / 2;
        }
    }

    int pop() {
        int top = a[0];
        a[0] = a.back();
        a.pop_back();
        int i = 0, n = (int)a.size();
        while (true) {
            int l = 2 * i + 1, r = 2 * i + 2, m = i;
            if (l < n && a[l] < a[m]) m = l;
            if (r < n && a[r] < a[m]) m = r;       // 두 자식 중 더 작은 쪽 선택
            if (m == i) break;
            std::swap(a[i], a[m]);
            i = m;
        }
        return top;
    }
};

2-3. heapify — 배열을 통째로 힙으로, O(N)

원소를 하나씩 push하면 O(N log N)이지만, 마지막 내부 노드부터 역순으로 sift-down 하면 O(N)에 만들 수 있다. 대부분의 노드가 트리 바닥 근처에 있어 이동 거리가 짧기 때문.

for (int i = n / 2 - 1; i >= 0; i--)
    sift_down(i);
연산복잡도
top (최솟값 조회)O(1)
push / popO(log N)
배열 → 힙 (heapify)O(N)
임의 원소 검색O(N) — 힙이 못 하는 것

3. std::priority_queue (C++)

#include <queue>

// 기본은 Max Heap (top이 최댓값)
std::priority_queue<int> max_pq;

// Min Heap — greater 비교자 지정
std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;

min_pq.push(3);
min_pq.push(1);
min_pq.push(2);
min_pq.top();   // 1
min_pq.pop();
  • C++ 기본이 Max Heap인 점 주의 (Python heapq는 반대로 Min Heap만 제공)
  • Min Heap을 급하게 쓸 때 흔한 트릭: 값을 음수로 넣고 꺼낼 때 다시 뒤집기 — 되긴 하지만 greater<int> 지정이 정석
  • pair를 넣으면 first 기준 우선 비교 → {우선순위, 데이터} 형태로 자주 사용

커스텀 비교자:

struct Task { int priority; int id; };

auto cmp = [](const Task& a, const Task& b) {
    return a.priority > b.priority;   // "a가 b보다 뒤"일 조건 → min heap
};
std::priority_queue<Task, std::vector<Task>, decltype(cmp)> pq(cmp);
  • 비교자는 sort와 같은 < 의미지만 결과는 반대로 나온다는 점이 헷갈리는 포인트: less → max heap, greater → min heap

4. 대표 활용 패턴

4-1. Top-K — 크기 k의 Min Heap 유지

“N개 중 가장 큰 k개"를 구할 때, min heap을 크기 k로 유지한다 (반대 방향 힙을 쓰는 것이 포인트).

// N개 스트림에서 가장 큰 k개 유지 — O(N log k), 메모리 O(k)
std::priority_queue<int, std::vector<int>, std::greater<int>> pq;
for (int x : stream) {
    if ((int)pq.size() < k) pq.push(x);
    else if (x > pq.top()) {    // 현재 top-k의 최솟값보다 크면 교체
        pq.pop();
        pq.push(x);
    }
}
  • 힙의 top이 “top-k 중 꼴찌” → 새 원소가 이것보다 크면 교체
  • 전체 데이터를 들고 있을 수 있다면 Quick Select (nth_element)가 평균 O(N)으로 더 빠르다. 스트림/대용량이라 메모리에 다 못 올릴 때 힙이 정답

4-2. Dijkstra 최단 경로

// {거리, 노드} min heap — 가장 가까운 미확정 노드를 O(log N)에 꺼냄
std::priority_queue<std::pair<int,int>,
                    std::vector<std::pair<int,int>>,
                    std::greater<>> pq;
pq.push({0, start});
  • 매 단계 “현재 최단 후보"를 꺼내는 구조가 정확히 min heap의 용도
  • 꺼냈을 때 이미 확정된 노드면 skip 하는 lazy deletion 방식이 일반적 (힙은 임의 원소 갱신이 안 되므로)

4-3. 그 외

  • Heap Sort: heapify O(N) 후 pop을 N번 → O(N log N), in-place. 캐시 지역성 문제로 실전 속도는 quick sort에 밀린다
  • K개 정렬 리스트 병합: 각 리스트의 머리만 힙에 유지 → O(전체 log K)
  • 중앙값 스트리밍: max heap(하위 절반) + min heap(상위 절반) 두 개를 균형 맞춰 유지 → 중앙값 O(1) 조회
  • 작업 스케줄러 / 타이머: “가장 빠른 마감/만료 시각"을 계속 꺼내는 구조. 커널 타이머, 이벤트 루프 등 시스템 프로그래밍에서도 같은 패턴

5. 정리 — 언제 힙인가

상황선택
최솟/최댓값을 반복해서 꺼내야 함힙 — pop O(log N)
값이 계속 흘러들어오며 상위 k개 유지크기 k min heap — O(N log k)
k번째 값 한 번만 (배열 보유)quick select — 평균 O(N)
임의 원소 검색/순회가 주 연산힙 부적합 → 정렬 배열, BST(std::set) 등
