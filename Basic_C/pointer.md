# Pointer란? 

메모리 주소를 저장하는 변수.

&와 *의 차이는 아래와 같다

1. & (주소 연산자, address-of)
변수 앞에 붙여서, 그 변수의 메모리 주소를 구합니다.

2. * (간접 참조 연산자, dereference)
포인터 변수 앞에 붙여서, 그 포인터가 가리키는 주소의 값을 가져옵니다.
즉, 주소를 “열어서 안에 있는 값”을 꺼내는 것.


```cpp
int a = 10;
int *p = &a;       // p에 a의 주소 저장
printf("%d\n", *p); // p가 가리키는 곳(a)의 값(10) 출력
*p = 20;            // p가 가리키는 곳(a)의 값을 20으로 변경
```
